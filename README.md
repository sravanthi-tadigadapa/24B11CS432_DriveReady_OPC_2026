## Daily Tasks

### Day 1 – Sweet Crumbs Home Bakery Assistant

Built a basic AI-powered customer support assistant for Sweet Crumbs Home Bakery using Python, LangChain, and Groq.

**Concepts Covered:**
- Introduction to AI Agents and LLMs
- LangChain integration with Groq
- System prompt engineering
- Interactive chatbot development
- API key management using environment variables

### Day 2 – Sweet Crumbs Home Bakery Chatbot

Extended the bakery chatbot with additional Python and AI capabilities.

**Concepts Covered:**
- Bakery menu and price calculation
- Python decorators and logging
- Few-shot message classification
- JSON-based order extraction
- Conversation history and memory
- API error handling

## How to Run

Clone the repository:

```bash
git clone https://github.com/sravanthi-tadigadapa/24B11CS432_DriveReady_OPC_2026.git
```

Navigate to the required day's folder:

```bash
cd 24B11CS432_DriveReady_OPC_2026/Day-1
```

Install the required dependencies mentioned in that day's README.md and run:

```bash
python task.py
```

For Day 2:

```bash
cd ../Day-2
python task.py
```

**Note:** Some tasks require API keys. Configure them using environment variables and never upload API keys or secrets to GitHub.
